A.51 デロスの結合 (DICTO DOI: 10.5281/zenodo.23606828)

第 I 巻 第2章 結合で語られています。

設定

辺 1 のオクテット：正四面体（体積 VT = √2/12）と正八面体（VO = √2/3 = 4VT）で、正八面体 1 個につき正四面体 2 個です。各正四面体はその中心 cT からの錐 4 個、各正八面体はその中心 cO からの錐 8 個からなります（面の角錐で、これらは合わせて空間を充填します、#44）。共有面 F について、二重錐 BF は cT から F を通って cO まで伸びます；cTcO は F に垂直で、F の中心で F と交わります；F は cT から cO までの 3 分の 1 の位置にあります（内接球の半径 1/(2√6) と 1/√6）。

用いる古典的な事実：菱形十二面体は、正八面体にその面の上の正四面体の錐 8 個を加えたものであり（その三回対称の頂点 8 個は隣の正四面体の中心にある；体積 VO + 8·VT/4 = 6VT）、同様に立方体に正四角錐 6 個を加えたものでもあります；辺 1/√2 の立方体は、正四面体にその面の上の正八面体の錐 4 個を加えたものです（残りの頂点 4 個は隣の正八面体の中心にある；体積 VT + 4·VO/8 = 3VT）。

主定理

0 ≤ t ≤ 1 について、すべての BF を、cT + t(cO − cT) を通り F に平行な平面で切ります；T(t) = 正四面体の中心に接する 4 つの部分、O(t) = 正八面体の中心に接する 8 つの部分。これらは面と面を合わせて空間を充填し、どちらも凸です。

  • (a) 0 < t ≤ 1/3：T(t) は辺 3t の正四面体、体積 27t³·VT；O(t) は三回対称の頂点 8 個を正八面体の面に平行な平面で切り落とした菱形十二面体（t < 1/3 では三角形 8 枚と六角形 12 枚）、体積 (6 − 54t³)·VT。
  • (b) 1/3 ≤ t < 1、a = 3(1 − t)/2：O(t) は辺 a の正八面体、体積 4a³·VT；T(t) は正八面体の中心にある頂点 4 個を切り落とした立方体（t > 1/3 では三角形 4 枚と六角形 6 枚）、体積 (3 − 2a³)·VT。
  • (c) t = 0：菱形十二面体のみ；t = 1/3：オクテット；t = 1：立方体のみ。

証明の概略。二重錐は空間を充填し、それぞれが一枚の平面で分けられるので、ピースは空間を充填します。t ≤ 1/3 では、平面は正四面体の錐の中、cT から F までの割合 3t の位置にあります：cT 側の部分は 3t 倍した正四面体をなし；cO 側の部分は 8 枚の平面で切った菱形十二面体で（cT は F の平面の向こう側にある唯一の頂点）、凸集合の共通部分として凸です；各平面は三回対称の頂点に集まる 3 本の辺を割合 3t で切ります。t ≥ 1/3 では、平面は cO から F までの割合 (3/2)(1 − t) = a の位置にあり、役割が入れ替わります（正八面体を a 倍；立方体を 4 枚の平面で切る）。体積：(a) 27t³VT と 6VT − 8·(VT/4)·27t³；(b) a³VO = 4a³VT と 3VT − 4·(VO/8)·a³。面と面：各三角形は、もう一方の種類の隣のピースの切断面です；六角形は同じ種類の隣どうしで共有され、同じ平面で切られています。

検証。有理数の算術で厳密、t = 1/10、1/5、1/3、1/2、4/5、9/10 で（octet/octet_exact.py → octet-exact.txt）。

定理 2（特別な一員）

  • (a) t = (2√6 − 3)/15：すべての辺（正四面体と、切った菱形十二面体）の長さが (2√6 − 3)/5。菱形十二面体の辺を √6/4 として、3t = (√6/4)(1 − 3t) から。
  • (b) t = 5/3 − (2/3)√2：すべての辺（切った立方体と正八面体）の長さが √2 − 1。立方体の辺を 1/√2 として、a = (1 − a)/√2 から。
  • (c) t = 1 − ∛6/3：正四面体側のピースと正八面体側のピースがそれぞれ空間のちょうど半分を占めます。2(3 − 2a³) = 4a³、a³ = 3/4 から（t ≤ 1/3 では正四面体側のピースが占めるのは高々 3 分の 1）。
  • (d) どの t でも六角形は正六角形になりません：切った立方体の六角形の角は 90°、135°、135°、90°、135°、135°；切った菱形十二面体の六角形は約 70.5° の鋭角を保ちます（切り落とした頂点で 144.7°）。

検証。(a)–(c) を ℚ(√6)、ℚ(√2)、ℚ(∛6) で厳密に、どの等式にも浮動小数点を使わずに（octet/octet_special_exact.py → octet-special-exact.txt）。

定理 3（デロスの結合）

T(t) と O(t) の体積が等しくなる位置はちょうど一つ、tD = 1 − (2/3)·2−1/3 です。そこでサムソン（切った立方体 T(tD)）とデリラ（正八面体 O(tD)）はどちらも体積 √2/6 = 2VT = VO/2 です。デリラはオクテットの正八面体を 2−1/3 倍に縮めたもので、辺 1/∛2。サムソンの辺：1/∛2（彼の三角形、すなわちデリラの面）と (1 − 2−1/3)/√2。

証明の概略。t ≤ 1/3 では T(t) の体積 ≤ VT、O(t) の体積 ≥ 4VT で、等しくなることはありません。t ≥ 1/3 では (3 − 2a³)VT は a とともに減少し 4a³VT は増加するので、解は高々一つ：3 − 2a³ = 4a³、a³ = 1/2、a = 2−1/3、tD = 1 − 2a/3。検証：ℚ(∛2) で厳密：体積が等しいこと、デリラの辺、サムソンの二つの辺の長さ。

黄金とキー付きの体積は正二十面体の辺 1、デロスはオクテットの辺 1 での値です。イコサックスとアンボーン・アックスはコジャほかの切頂八面体（x = τ と x = 1/τ）で、新しい道筋でそこに到達しています；ロータス・ジュエル・アックスとドデカックスは新しいものです（#48）。

注記：立方体

立方体の格子とその立方体の中心とのあいだで、重み w をつけた同じ切断（パワー図）：w = 1/4 − 1/√2 で（アルキメデスの）切頂六面体と正八面体（立方体の辺 1 ですべての辺が √2 − 1）；w = −1/4 で立方八面体と正八面体（#48 の x → 0）；w = 0 でケルビンの切頂八面体（x = 1）；そのあいだでは、w = (x − 1)/(4(x + 1)) で #48 の T(x) と T(1/x)。辺がすべて等しい一員は、一様な空間充填形（ハニカム）である切頂立方体充填（truncated cubic honeycomb）と中点切頂立方体充填（rectified cubic honeycomb）です；体積が等しくなるのはケルビンのセルだけです。比 2 : 1 は x ≈ 0.3747 で起こり、これは 16u³ − 36u² + 18u − 1 = 0 の根で、この式は既約で実根を三つもつので、実数の冪根による表示はありません。新しい結合はありません；厳密に確認（changeover/changeover_exact.py → changeover-exact.txt）。

注記：黄金の結合の極双対

DICTO の着想：立体を裏返すこと（中心に関する極変換）。#48 の T(x)（正方形は距離 (1 + x)s、六角形は (1 + 2x)s/√3、尺度 s）の極双対は、各面に低い角錐を載せた立方体（頂点 14、三角形 24、四方六面体の型）で、角錐の高さは自身の立方体の辺の半分を単位として x/(1 + x)：イコサックス（x = τ）では 1/φ、アンボーン・アックス（x = 1/τ）では 1/φ²、ケルビンのセルでは 1/2；x と 1/x の組ごとに高さの和は 1 で、これは立方体を菱形十二面体にする角錐の高さです。これは比率についての主張です（二つの極双対の立方体は大きさが異なる）。デリラの極双対：立方体；サムソンの極双対：一つおきの四つの面に低い角錐を載せた正八面体；キー付きの立体は凸でなく、極双対の立体をもちません。極双対の立体が空間を充填するとは主張していません。
