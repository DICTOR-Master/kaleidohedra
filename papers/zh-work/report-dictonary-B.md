## Problems found in the English (kept as written)
1. 007: the Dehn-invariant bullet writes "3 AXE + CLEO + t1" and then "3 AXE + CLEO + t1′" for the same mix.
2. 008: "Base angles" L, S are the angles between side faces and base (the proof uses distance and slant), but 007 uses "base angles" for the hexagon's plane angles (120°). Rendered literally 底角 both times; the lead may want 底棱二面角 in 008.
3. 009/010: the same 20 vertices of the pentakis dodecahedron are "three-fold" (by symmetry, 009 and 010 Relation) and "six-fold corners" (by valence, 010 Face arrangement). Not wrong, but it reads like a contradiction. Also "Shield apices" (009) vs "Shield apexes" (010).
4. 016: Conjecture 1 says "the face-axis width (tetrahedron: √3 − √2/2)", but the bullet before gives that tetrahedron value along the edge-midpoint axis, not a face axis.
5. 018: Tsai ratio 0.188/0.301 = 0.6246, which rounds to 0.625; printed 0.626 (could come from the unrounded coordinates).
6. 022: the code {x : x₁ + 3x₂ + 9x₃ ≡ 0 (mod 13)} does not hold for the given basis in ordinary coordinates ((−3, 0, 1) gives 6 mod 13), so it must use other coordinates (e.g. lattice-basis ones), which the text does not say.
7. 025: "Cleo-Ico (5 + √5)/8": typo for Cleo-Icos; kept.
8. 025: "66 prolate and −30 oblate per cell": a negative count, presumably a signed count; not explained.
9. 026, Kit 2: the sum uses "6 × 0.058072", a value given nowhere in the text (it equals (notched octahedron − OG)/6).
10. 026 table: "Keyless kit, three cores" lists six shapes with mirror pairs counted once (OG, cap, central core, flanking core L/R, rest, tetrahedron L/R) but says (5).
11. 026 table: row "OG + keyed Wstar", shapes column "OG, keyed W".
12. 020: "hidden gaps 0.0067 to 0.263 of an edge, 76.2% of its hull": it is unclear what fills 76.2% (presumably the shell). Rendered literally.
13. 005 opens <section class="appendix"> and does not close it in this file (closed later, presumably); kept.
