除标注“浮点”者外，均在 ℚ(√5) 中精确。

  • 正八面体 |x| + |y| + |z| = R，R = 2φ/3（棱长 2√2φ/3 ≈ 1.5255）；48 个 OG 顶点位于其上。OG (−1000 + 1240√5)/1539 ≈ 1.151868，占其正八面体的 68.83%；六个帽，每个 (1108 − 316√5)/4617 ≈ 0.086940。
  • 单元：(64 + 32√5)/81 + 2 · (16 + 8√5)/81 = (32 + 16√5)/27 ≈ 2.510263；仅 OG 占 (1025 − 435√5)/114 ≈ 45.886%。
  • 套件 1：钥（内切球半径为 2/3 的菱形三十面体的三重顶点，位于 |x| + |y| + |z| = 2/φ 处）(−44 + 20√5)/81 ≈ 0.008906；侧面为半个黄金菱形（31.72°、31.72°、116.57°）。带钥 OG (−7688 + 4280√5)/1539 ≈ 1.223113；凹陷四面体 64/27 − 8√5/9 ≈ 0.382754（15.25%，ψ 0.620，手性）；带钥八面体 −32/9 + 64√5/27 ≈ 1.744754（69.50%，ψ 0.852）。
  • 套件 2：星尖半径 0.350487；半转 36°；c2 沿轴近 0.0943。彭罗斯菱形的棱长为尖端半径 ÷ φ ≈ 0.2166，较小的 ≈ 0.1339。凸包 H 4√5/81；中间块 M0 (310 + 26√5)/4617 ≈ 0.079735；中心核心 (−36734 + 16658√5)/50787 ≈ 0.010129；侧翼核心每个 4114/1539 − 9182√5/7695 ≈ 0.004993（一个镜像对）；其余部分 −231380/50787 + 524152√5/253935 ≈ 0.059620。带凹口正八面体 8/57 + 104√5/171 ≈ 1.500299（59.77%）；带凹口四面体 26/81 − 2√5/81 ≈ 0.265776。每单元 1.151868 + 6 × 0.058072 + 6 × 0.079735 + 2 × 0.265776 = 该单元。
  • 套件 3：包络 (−320 + 160√5)/27 ≈ 1.398921；最近距离 2/(3φ³√(φ√5)) ≈ 0.0827；填充率 90 − 40√5 = 10/φ⁶ ≈ 55.728%。顶点立方八面体（缩放 φ⁻²）(−320 + 160√5)/81，18.576%。生长块 G = 立方体 − RT/2 = (176 − 72√5)/27 ≈ 0.555671：44 个顶点，72 条棱，30 个面，二面角 90°、108°、216°，ψ = 0.6025，对称性 T。五角三四面体 (−146 + 66√5)/27 ≈ 0.058537，棱 ≈ 0.157（= R/φ⁴）、0.242、0.299。
  • 套件 4：W (352 − 144√5)/27 = 2G，m3̄，ψ 0.574，最锐的棱 77.4°。WOG = 单元 − OG = (2824 − 328√5)/1539 ≈ 1.358395（54.11%），132 个面（120 个印痕 = 一个完整的 OG 表面），最锐的棱 86.9°，插座间距 √(70/81 − 10√5/27) ≈ 0.18980，ψ 0.648。带钥 W（浮点）：筝形钥的棱 0.2379 与 0.1971；6 000 000 个采样点；600 个方向，无一自由（无钥时：41）。
