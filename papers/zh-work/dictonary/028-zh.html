框架：正八面体 |x| + |y| + |z| ≤ R，R = 2φ/3；晶胞 (32 + 16√5)/27；层 (2k − 1)R ≤ x + y + z ≤ (2k + 1)R。步骤 c（平移）与 h（关于共享平面的镜像）；Jagodzinski 记号。

孪晶规则，证明。关于过中心的平面的镜像 M 等于 −H（反演与绕 n 的半周旋转 H 的复合）。由 S = −S，得 M(S) = H(S)；H = T⁶⁰∘T¹²⁰ 且 T¹²⁰(S) = S，故 H(S) = T⁶⁰(S)。嵌合规则，证明。各层是互不相交的板层；每一层都是参考层经平移或镜像所得，后者给出转过 60° 的立体。
