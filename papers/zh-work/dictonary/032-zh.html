A.48 黄金剖分 （DICTO DOI: 10.5281/zenodo.23596362）

讲述见第 I 卷第2章 · 键。

φ = τ = (1 + √5)/2。棱长 1 的正二十面体位于 φℤ³，顶点 (0, ±½, ±φ/2) 及其轮换。晶胞 φ³ = 2 + √5。

  • 正二十面体 (15 + 5√5)/12。未生体位于 c = (φ/2, φ/2, φ/2)，顶点 c + (±φ/2, ±1/(2φ), 0) 及其轮换：24 条棱长 1，6 条棱长 1/φ；8 个正三角形与 12 个等腰三角形 (1, 1, 1/φ) 面；体积 (3 + 7√5)/12（Koca et al.，x = 1/τ）。AXE：按 1/τ 缩放的莫塞里-萨多克瓦片 t6，五条棱长 1，一条 1/φ，体积 1/12，每个晶胞六个。
  • 三帽体（按 1/τ 缩放的 t3）(3 − √5)/24；莲花宝石 J (1 + 3√5)/4；正十二面体 D（棱长 1/φ）(15 + 3√5)/12。每个晶胞 I + U + 6 AXE = J + D + 6 AXE = φ³。
  • 在 p(t) = m1 + t(m2 − m1) 处剖分；黄金剖分 t = 1/φ。
  • 二十面斧：截角八面体，顶点为 (±½, ±φ/2, 0) 的全部排列；体积 1 + 2√5/3。未生斧：顶点 c + (±1/(2φ), ±φ/2, 0) 的全部排列；体积 1 + √5/3。合计 φ³。六边形等角，边长交替为 1/√2 与 1/(φ√2)；正方形 1/√2 与 1/(φ√2)。尖顶是核心关于 x = y 的镜像的顶点。
  • 唯一性：对于顶点为 (∓½, φ/2, 0)、(0, φ/2 ± 1/(2φ), φ/2) 的 AXE，平面 x + y + z = φ²/2、−x + y + z = φ²/2、x − y + z = −1/(2φ)、−x − y + z = −1/(2φ) 仅交于 (0, φ/2, ½) = p(1/φ)；24 个尖顶-面对，距离恰在 t = 1/φ 时为零。
  • 凸包填充率（浮点）：I(t) 在 t ≤ 1/φ 时为 100%，93.6%（0.7），86.9%（0.8），76.0%（1）；U(t) 58.2%（0），67.6%（0.2），79.8%（0.4），97.9%（0.6），t ≥ 1/φ 时为 100%。整块 AXE 归入正二十面体：一个星形，68.2%。
  • 带钥对：莲花宝石斧 1 + 2√5/3 − 8(3 − √5)/24 = √5；十二面斧 1 + √5/3 + 8(3 − √5)/24 = 2。
  • 定理 4：T(x) = (±(1 + x), ±x, 0) 全部排列的凸包，正方形位于距离 L/2 处；位于 Lℤ³ 的 T(x) 与位于 (L/2)(1, 1, 1) + Lℤ³ 的 T(1/x) 面对面地填充空间，体积之和为 L³。T(x) = 立方体 |pi| ≤ L/2 ∩ 正八面体 |p1| + |p2| + |p3| ≤ k(x)，k(x) = L(1 + 2x)/(2(1 + x))；k(x) + k(1/x) = 3L/2；在小立方体 [0, L/2]³ 中，切面为 p1 + p2 + p3 = k(x)。在 x = 0.3、0.5、1/τ、0.8、1、1.25、τ、2、3 处做 300,000 点检验。x → 0：正八面体与立方八面体（截半立方蜂巢）；x = 1：开尔文；x = τ：黄金对。
  • 已知：Koca, Koca, Al-Mukhaini and Al-Qanobi（式 39、49：伪二十面体及其镜像 = 截角八面体；x = τ 与 1/τ）；Polytope Wiki（半均匀截角八面体；交错给出黄铁矿型二十面体，在棱长比 (√5 − 1)/2 时为正二十面体）；加权沃罗诺伊胞；α-(AlMnSi)（Pm3̄）；该填充具有 Pm3̄m。

核验与来源。全部在 ℚ(√5) 中精确，无浮点运算（研究 [8a]）；凸性由并集与凸包体积相等确认。已知：Koca et al.（伪二十面体，截角八面体）；莫塞里-萨多克瓦片；Kelvin；DICTO #19、#47，Kaleidohedra F21。研究提交 066a46a。
