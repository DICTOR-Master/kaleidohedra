A.35a DICTO间六十面体 （DICTO DOI: 10.5281/zenodo.23430864）

讲述于第 I 卷，第1章 · 原子。

在 ℚ(√5) 中精确。正二十面体 (0, ±1, ±φ) 及其循环置换（棱长 2）；正十二面体 (±1, ±1, ±1) 及 (0, ±φ, ±1/φ) 的循环置换，其顶点位于正二十面体各面中心的上方（棱长 2/φ），缩放 k 倍；凸包的棱长比（正二十面体 : 正十二面体）为 φ/k。M：k = φ⁵/9 = 11/18 + 5√5/18，比 9/φ⁴ ≈ 1.31308（平方 81/φ⁸）。闭合形式：(0, ±1, ±φ) 与 (φ⁵/9)·{(±1, ±1, ±1), (0, ±φ, ±1/φ)}（循环）的凸包。

性质值（精确）
顶点32：12 个五重顶点（正二十面体的），20 个三重顶点（正十二面体的）
面、棱60 个全等的等腰三角形，90 条棱；五角化十二面体的组合结构
棱长平方94/81 + 14√5/27（60 条棱，五重到三重）；14/9 + 2√5/27（30 条棱，三重到三重）
顶点半径平方5/2 + √5/2（五重）；41/18 + 55√5/54（三重）
内切球全部 60 个面位于距离平方 7249/4162 + 16209√5/20810 处
中分球无：棱位于距离平方 2 + 20√5/27 与 161/81 + 8√5/9 处
体积410/27 + 550√5/81 ≈ 30.3684

在循环中

  • 三十面体只达到 RT → I·φ³ 这一步的 0.812；没有任何具有正二十面体对称的凸立体同时与两个邻居相切（《金刚乘》，表 3，浮点）。
  • 以循环的单位表示：RT 的 12 个五重顶点与 I·φ³ 的 20 个面中心的凸包（半径平方 45/8 − 9√5/8 与 47/24 + 7√5/8）；为同一立体，已精确核验。
  • RT → M：30 个同一种类的块体；M → I·φ³：60 个同一种类的块体（三角双锥形状）；M 占该步体积的 0.356。
  • 配极：12 个正五边形与 20 个六边形，六边形的边长按 (14 + 9√5)/11 之比交替。
  • 家族：棱长比在 (5 + 3√5)/10 至 φ 之间时具有完全对称；卡塔兰立体五角化十二面体 3(7 + 5√5)/38 ≈ 1.435；复三十面体 3/√5 ≈ 1.342；间六十面体 9/φ⁴ ≈ 1.313。9/φ⁴ 也恰是最紧的始祖循环每一轮的增益（仅作记录，未作解释）。
