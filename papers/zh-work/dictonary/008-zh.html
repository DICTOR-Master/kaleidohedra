FUJI(r) 家族

  • 底面：边长为 1 与 r 的截角三角形（边长为 1 + 2r 的正三角形切去边长为 r 的三个角；即顶点可递六边形，或截角三角形 t{3}）；顶点位于半径平方为 (1 + r + r²)/3 的圆上。
  • 当 h² = (2 − r − r²)/3 时侧棱为 1。体积 (√3/12)(1 + 4r + r²)h。侧面：三个正三角形，三个边长为 1、1、r 的等腰三角形。
  • 底角：cos L = (1 + 2r)/3（长边）；cos² S = (2 + r)/(3(2 − r))（短边）。证明：长边的距离为 s/(2√3)，其中 s = 1 + 2r，斜高 √3/2；切线的距离为 (2 + r)/(2√3)，斜高 √(1 − r²/4)。

奥多姆与反棱柱规则

  • 将正三角形的每条边在两端各延长 e，得到边长为 e 与 1 + e 的截角三角形，r = e/(1 + e)；e = φ 给出FUJI的底面（Kabai 2008，继 Odom 之后）；e = 1 给出 r = 1/2。这只是参数的变换，不是新结果。
  • 面平面条件 L + DX = 180°：r = (−3 cos DX − 1)/2。正二十面体（138.19°）：1/φ；立方八面体，三角形–正方形（125.26°）：(√3 − 1)/2；正四角反棱柱（127.55°）：√2 − 1；小斜方截半立方体（144.74°）：(√6 − 1)/2；正八面体（109.47°）：0。
  • 命题 1：对于 n 角反棱柱，r = 2 cos(π/n) − 1，因此 1 + r 是正 n 边形的短对角线。证明：顶点 Tk、Bk，θ = π/n，R = 1/(2 sin θ)；(T₁ − M)·(B₋₁ − M) = −(4 cos θ − 1)/4，故 cos Dn = (1 − 4 cos(π/n))/3（标准的反棱柱二面角，见 OEIS）。数值核验 n = 3 至 12，精度 10⁻¹²。
  • n = 3：正四面体；n = 4：√2 − 1（白银比的倒数）；n = 5：1/φ，FUJI；n = 6：√3 − 1。截角 k 边形仅在 k = 3、4 与 5 时给出家族（在 r = 2 sin(π/k − π/6) 时变为扁平）；正方形家族中的小斜方截半立方体成员为 r = 1 − 1/√2。与八次对称准晶体的联系尚未解决。

各成员出现之处

  • Damasceno、Engel 与 Glotzer（2012）：t = 1/2 的截角四面体填充空间；其六边形的边长比为 2 : 1，即 r = 1/2 的底面。
  • 呼吸型烧绿石（棱长 1 与 r）：每个笼目六边形的边长为 1 与 r；用两种截角四面体，对每个 r 都能填充空间（Ã₃ 中的维特霍夫构造）；在 r = 0.2、0.382、0.5、0.618、0.8、1 处作了数值核验。r = 1/φ：黄金呼吸型烧绿石。
  • 等深立方体–八面体立体（|x|, |y|, |z| ≤ 1, |x| + |y| + |z| ≤ √3）：6 个正方形，8 个 r = (√3 − 1)/2 = 0.366 的截角三角形，全部 14 个面都与同一个内切球相切；其立方体顶点是放大 √2(√3 − 1) ≈ 1.035 倍的 FUJI((√3 − 1)/2) 的锥顶。证明：长面为正三角形当且仅当 2(S − 1)² = (2 − S)² + 1，即 S² = 3。

轮、CLEO球、Cleo-Icos与安东尼乌斯

  • 轮的界：n 个各有 2m 根辐条的轮需满足 n − 1 ≤ m：至多 3 个（正方形）、4 个（六边形）、6 个（十边形）。五个八边形轮：简单排列中的三角形（边长 45°）的角为 65.53°，迫使五边形的角为 114.47°，而边长 45° 的等边等角球面五边形的角为 122.25°。
  • CLEO球（CLEO sphere）：棱长为 1/φ（外接球半径 1）的截半二十面体 = 20 CLEO + 12 个五棱锥（每个体积 √5/12）；总计 (11√5 − 5)/6。每个五棱锥 = 5 个体积为 √5/60 的直棱锥。
  • Cleo-Icos：侧棱 0.851，底棱 2/√5 = 0.894；麦凯的单位四面体（棱长比 1/sin 72° = 1.0515）；许普西克勒斯的棱锥（内切球半径 ÷ 外接球半径 = 0.79465）。二面角 72°（侧棱）与 69.09°（底棱）。
  • 长形黄金菱面体（棱长 0.851，二面角 72° 与 108°），0 ≤ x, y, z ≤ 1，被 x + y + z = 1 与 2 切开：Cleo-Icos + 安东尼乌斯 + Cleo-Icos。安东尼乌斯：三角反棱柱，两个正三角形面（棱长 2/√5），六个侧面（0.851、0.851、0.894）；体积为 4 × Cleo-Icos 的体积；菱面体为 6 ×。安东尼乌斯的二面角 110.91° + 69.09° = 180°。核验了 2,187 个块体的拼片。安东尼乌斯的德恩不变量恰为 Cleo-Icos 的 −2 倍。
  • 正八面体 = 20 Cleo-Icos + 12 个半提督帽（正二十面体棱长为 1 时，体积分别为 φ²/24、φ/24、φ⁶/6）= 8 Cleo-Icos + 12 个筝形棱锥；Cleo-Icos 与半帽（无论有无安东尼乌斯）都不能填充空间（π、arccos(−√5/3)、arccos(1/√3) 有理无关）。
