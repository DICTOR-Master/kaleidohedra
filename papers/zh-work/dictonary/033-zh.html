A.51 提洛键 （DICTO DOI: 10.5281/zenodo.23606828）

讲述见第 I 卷第2章 · 键。

设定

棱长 1 的八隅结构：正四面体，体积 VT = √2/12，与正八面体，VO = √2/3 = 4VT，每个正八面体配两个正四面体。每个正四面体是从其中心 cT 出发的 4 个锥体，每个正八面体是从其中心 cO 出发的 8 个锥体（即中心棱锥，它们共同填充空间，#44）。对于共享面 F，双锥体 BF 从 cT 经 F 延伸到 cO；cTcO 垂直于 F 并交于其中心；F 位于从 cT 到 cO 的三分之一处（内切球半径 1/(2√6) 与 1/√6）。

所用的经典事实：菱形十二面体是在正八面体的各面上加上 8 个正四面体锥体（其 8 个三重顶点位于相邻正四面体的中心；体积 VO + 8·VT/4 = 6VT），同样也是立方体加上六个四棱锥；棱长 1/√2 的立方体是在正四面体的各面上加上 4 个正八面体锥体（另外四个顶点位于相邻正八面体的中心；体积 VT + 4·VO/8 = 3VT）。

主定理

对 0 ≤ t ≤ 1，用过 cT + t(cO − cT) 且平行于 F 的平面切割每个 BF；T(t) = 靠近一个正四面体中心的 4 个部分，O(t) = 靠近一个正八面体中心的 8 个部分。它们面对面地填充空间，且两者均为凸。

  • (a) 0 < t ≤ 1/3：T(t) 为棱长 3t 的正四面体，体积 27t³·VT；O(t) 为菱形十二面体，其 8 个三重顶点被平行于正八面体各面的平面切去（t < 1/3 时有 8 个三角形与 12 个六边形），体积 (6 − 54t³)·VT。
  • (b) 1/3 ≤ t < 1，a = 3(1 − t)/2：O(t) 为棱长 a 的正八面体，体积 4a³·VT；T(t) 为立方体，其位于正八面体中心的 4 个顶点被切去（t > 1/3 时有 4 个三角形与 6 个六边形），体积 (3 − 2a³)·VT。
  • (c) t = 0：仅菱形十二面体；t = 1/3：八隅结构；t = 1：仅立方体。

证明概要。双锥体填充空间，且每个双锥体被一个平面分割，故各块填充空间。t ≤ 1/3 时，该平面位于正四面体的锥体内，处于从 cT 到 F 的 3t 处：靠近 cT 的各部分组成按 3t 缩放的正四面体；靠近 cO 的各部分是被 8 个平面切割的菱形十二面体（cT 是它在 F 所在平面之外唯一的顶点），作为凸集之交而为凸；每个平面在一个三重顶点处的三条棱的 3t 处切割它们。t ≥ 1/3 时，该平面位于从 cO 到 F 的 (3/2)(1 − t) = a 处，角色互换（按 a 缩放的正八面体；被 4 个平面切割的立方体）。体积：(a) 27t³VT 与 6VT − 8·(VT/4)·27t³；(b) a³VO = 4a³VT 与 3VT − 4·(VO/8)·a³。面对面：每个三角形都是其另一类相邻块的切面；六边形由同类相邻块共享，被同一组平面切出。

核验。在 t = 1/10、1/5、1/3、1/2、4/5、9/10 处以有理算术精确核验（octet/octet_exact.py → octet-exact.txt）。

定理 2（特殊成员）

  • (a) t = (2√6 − 3)/15：每条棱（正四面体与切割后的菱形十二面体）长 (2√6 − 3)/5。由 3t = (√6/4)(1 − 3t) 得出，菱形十二面体的棱长为 √6/4。
  • (b) t = 5/3 − (2/3)√2：每条棱（切割后的立方体与正八面体）长 √2 − 1。由 a = (1 − a)/√2 得出，立方体的棱长为 1/√2。
  • (c) t = 1 − ∛6/3：四面体块与八面体块各恰好填充空间的一半。由 2(3 − 2a³) = 4a³，a³ = 3/4 得出（t ≤ 1/3 时四面体块至多占三分之一）。
  • (d) 对任何 t，六边形都不是正六边形：切割立方体的六边形各角为 90°、135°、135°、90°、135°、135°；切割菱形十二面体的六边形保留约 70.5° 的锐角（切去的顶点处为 144.7°）。

核验。(a)–(c) 分别在 ℚ(√6)、ℚ(√2) 与 ℚ(∛6) 中精确核验，任何等式均不用浮点（octet/octet_special_exact.py → octet-special-exact.txt）。

定理 3（提洛键）

T(t) 与 O(t) 恰在一个位置体积相等，tD = 1 − (2/3)·2−1/3。在该处，参孙（切割后的立方体 T(tD)）与大利拉（正八面体 O(tD)）的体积均为 √2/6 = 2VT = VO/2。大利拉是八隅结构的正八面体缩小 2−1/3 倍：棱长 1/∛2。参孙的棱：1/∛2（他的三角形面，即大利拉的面）与 (1 − 2−1/3)/√2。

证明概要。t ≤ 1/3 时，vol T(t) ≤ VT 且 vol O(t) ≥ 4VT：永不相等。t ≥ 1/3 时，(3 − 2a³)VT 随 a 递减而 4a³VT 随 a 递增，故至多一个解：3 − 2a³ = 4a³，a³ = 1/2，a = 2−1/3，tD = 1 − 2a/3。核验：在 ℚ(∛2) 中精确：体积相等、大利拉的棱、参孙的两种棱长。

注：立方体

在立方体晶格与其立方体中心之间做同样的加权切割，权重为 w（幂图）：w = 1/4 − 1/√2 时为正截角立方体配正八面体（立方体棱长 1 时每条棱长 √2 − 1）；w = −1/4 时为立方八面体配正八面体（#48 的 x → 0）；w = 0 时为开尔文的截角八面体（x = 1）；其间为 #48 的 T(x) 与 T(1/x)，w = (x − 1)/(4(x + 1))。等棱成员是均匀截角立方蜂巢与截半立方蜂巢；仅开尔文的胞体积相等。比值 2 : 1 出现在 x ≈ 0.3747，即 16u³ − 36u² + 18u − 1 = 0 的一个根，该多项式不可约且有三个实根，因此无法用实根式表示。没有新的键；已精确核验（changeover/changeover_exact.py → changeover-exact.txt）。

注：黄金键的配极

DICTO的构想：将立体内外翻转（关于其中心的配极变换）。#48 的 T(x)（正方形位于距离 (1 + x)s 处，六边形位于 (1 + 2x)s/√3 处，尺度 s）的配极是每个面上有一个低棱锥的立方体（14 个顶点，24 个三角形，四角化六面体的类型），棱锥高以其自身的半个立方体棱长计为 x/(1 + x)：二十面斧（x = τ）为 1/φ，未生斧（x = 1/τ）为 1/φ²，开尔文的胞为 1/2；对每一对 x、1/x，高度之和为 1，即把立方体变为菱形十二面体的棱锥的高度。这是关于比例的陈述（两个配极的立方体大小不同）。大利拉的配极：立方体；参孙的配极：在四个交替的面上有低棱锥的正八面体；带钥立体不是凸的，没有配极立体。不主张这些配极立体能填充空间。
