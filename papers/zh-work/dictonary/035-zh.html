对偶的加权德洛内胞

  • 黄金键，0 < x < ∞：体心立方的双楔四面体（2 个大 + 2 个小，体积 2/3），无翻转；x = 0 与 ∞：四角双锥（2 + 4 个位点，体积 8/3）。
  • 提洛键，t < 1/3：正八面体（6 个 O，体积 4/3）与四面体（3 个 O + 1 个 Q，体积 1/12）；t = 1/3：菱形十二面体（6 个 O + 8 个 Q，体积 2）；t > 1/3：立方体（8 个 Q，体积 1）与四棱锥（1 个 O + 4 个 Q，体积 1/6）。在 t = 1/3 处，每个 RD 菱形以其长对角线（八面体–八面体）换成短对角线（四面体–四面体）：单一翻转。
  • 提洛键权重 3/8 − 22/3/4 ≈ −0.0218；八面体–四面体/四面体–四面体 = 21/3√3/(4 − 2·21/3)。
