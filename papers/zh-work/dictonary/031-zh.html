A.47 柏拉图立体的任意混合都能填充空间 （DICTO DOI: 10.5281/zenodo.23551326）

讲述见第 I 卷第2章 · 键。

所有立体均为正多面体，棱长 1；φ = (1 + √5)/2；31 种混合。瓦片不必面对面相接。

屋顶 (1 + 3φ/2)/6 ≈ 0.57118。P、Q、Q′、Y 为凸；A、S、X 不是。六个提督帽 = 一个天狼星 = φ/2。

  • 引理 1（堆垛）：板层以任意顺序堆垛并重复，即可密铺空间。
  • 引理 2（立方体板层）：厚度为整数。
  • 引理 3（八隅结构板层）：s = 1/√2；顶点 s(x, y, z)，x + y + z 为偶数；正八面体位于和为奇数处；平面 z = ks 由正八面体的正方形赤道面密铺；板层的面上带有半个正八面体 P；缺 O 时 → 两个 P；缺 T 时 → 四个 Q。
  • 引理 4（正二十面体板层）：正二十面体 ½(0, ±1, ±φ) 位于 |x| + |y| + |z| ≤ φ²/2（棱长 L）之内，其顶点按黄金比分其棱；棱长 L 的八隅结构，其中正八面体 = 正二十面体 + 6 A，正四面体 = 4 Q′。
  • 引理 5（正十二面体板层）：棱长 φ 的立方晶格，三层，厚度 3φ；屋顶高 ½ < φ。
  • 推论 1 由 #44 的计数映射得出（h(θD) = 1，h(θI) = 1，h(α) = 1）。推论 2：五种全用，配以 P、Q′、A、S、X、Y。

推论 3：棱长 L 的正八面体 φ⁶/6 = (8φ + 5)/6；正二十面体 5φ²/6 = (5φ + 5)/6；六个帽块 = φ/2；天狼星 = 2φ³ − (2 + 7φ/2) = φ/2（立方体的两倍减去正十二面体）；原因未知。待解决：不用连接块的 C + T + O；最小套件；面对面；三个方向上的周期性（基于 1、φ 与 φ²/√2 构建的板层周期不必相合）。桥接（§5）：正四面体 + 截角四面体，以及正八面体 + 立方八面体（均匀蜂巢）。

核验与来源。mixes3.py：全部 31 种堆叠，每种 40 000 个随机点，每个点都被覆盖且总和恰为 1（数值抽查）；volumes.py。已知：Gabbrielli, Jiao and Torquato（一种或两种立体）；Hart（天狼星密铺）；Pacioli；Euclid。研究提交 cea1e4a。
