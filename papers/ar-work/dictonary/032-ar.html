A.48 الانشطار الذهبي (DICTO DOI: 10.5281/zenodo.23596362)

يُروى في المجلد I، الفصل 2 · الروابط.

φ = τ = (1 + √5)/2. عشرونيات وجوه حرفها 1 عند φℤ³، رؤوسها (0, ±½, ±φ/2) وتبديلاتها الدورية. الخلية φ³ = 2 + √5.

  • عشروني الوجوه (15 + 5√5)/12. اللامولود عند c = (φ/2, φ/2, φ/2)، رؤوسه c + (±φ/2, ±1/(2φ), 0) وتبديلاتها الدورية: 24 حرفًا طولها 1، و6 أحرف طولها 1/φ؛ 8 وجوه متساوية الأضلاع و12 وجهًا متساوي الساقين (1, 1, 1/φ)؛ الحجم (3 + 7√5)/12 (Koca et al.، x = 1/τ). AXE: البلاطة t6 لموسيري–سادوك بمقياس 1/τ، خمسة أحرف طولها 1 وحرف واحد 1/φ، الحجم 1/12، ست في كل خلية.
  • ثلاثي القلنسوات (t3 بمقياس 1/τ) (3 − √5)/24؛ جوهرة اللوتس J (1 + 3√5)/4؛ اثنا عشري الوجوه D (الحرف 1/φ) (15 + 3√5)/12. لكل خلية I + U + 6 AXE = J + D + 6 AXE = φ³.
  • الانشطار عند p(t) = m1 + t(m2 − m1)؛ الانشطار الذهبي t = 1/φ.
  • الفأس العشرونية: ثماني وجوه مبتور، رؤوسه جميع تبديلات (±½, ±φ/2, 0)؛ الحجم 1 + 2√5/3. فأس اللامولود: رؤوسها c + جميع تبديلات (±1/(2φ), ±φ/2, 0)؛ الحجم 1 + √5/3. معًا φ³. المسدسات متساوية الزوايا، أضلاعها بالتناوب 1/√2 و1/(φ√2)؛ والمربعات 1/√2 و1/(φ√2). القمم هي رؤوس الصورة المرآوية للنواة في x = y.
  • الوحدانية: لقطعة AXE ذات الرؤوس (∓½, φ/2, 0), (0, φ/2 ± 1/(2φ), φ/2)، المستويات x + y + z = φ²/2، −x + y + z = φ²/2، x − y + z = −1/(2φ)، −x − y + z = −1/(2φ) لا تلتقي إلا في (0, φ/2, ½) = p(1/φ)؛ 24 زوجًا من قمة ووجه، والمسافة صفر بالضبط عند t = 1/φ.
  • امتلاء الغلاف (عائم): I(t) 100% عند t ≤ 1/φ، و93.6% (0.7)، 86.9% (0.8)، 76.0% (1)؛ U(t) 58.2% (0)، 67.6% (0.2)، 79.8% (0.4)، 97.9% (0.6)، و100% عند t ≥ 1/φ. قطعة AXE كاملة مضافة إلى عشروني الوجوه: نجمة بنسبة 68.2%.
  • الزوج المُفتاحي: فأس جوهرة اللوتس 1 + 2√5/3 − 8(3 − √5)/24 = √5؛ الفأس الاثنا عشرية 1 + √5/3 + 8(3 − √5)/24 = 2.
  • المبرهنة 4: T(x) = غلاف جميع تبديلات (±(1 + x), ±x, 0)، والمربعات على بعد L/2؛ T(x) عند Lℤ³ وT(1/x) عند (L/2)(1, 1, 1) + Lℤ³ تملأ الفضاء وجهًا لوجه، ومجموع حجميهما L³. T(x) = المكعب |pi| ≤ L/2 ∩ ثماني الوجوه |p1| + |p2| + |p3| ≤ k(x)، k(x) = L(1 + 2x)/(2(1 + x))؛ k(x) + k(1/x) = 3L/2؛ وفي المكعب الصغير [0, L/2]³ يكون القطع p1 + p2 + p3 = k(x). اختبار بـ300,000 نقطة عند x = 0.3, 0.5, 1/τ, 0.8, 1, 1.25, τ, 2, 3. x → 0: ثمانيات وجوه مع ذوات وجوه مكعبية ثمانية (الشهد المكعبي المُقوَّم)؛ x = 1: كلفن؛ x = τ: الزوج الذهبي.
  • معروف: Koca, Koca, Al-Mukhaini and Al-Qanobi (المعادلتان 39 و49: شبه عشروني الوجوه وصورته المرآوية = ثماني وجوه مبتور؛ x = τ و1/τ)؛ Polytope Wiki (ثماني الوجوه المبتور شبه الموحَّد؛ التناوب يعطي عشروني الوجوه البيريتي، المنتظم عند نسبة الأحرف (√5 − 1)/2)؛ خلايا فورونوي الموزونة؛ α-(AlMnSi) (Pm3̄)؛ وللتعبئة التناظر Pm3̄m.
