# Proposed DICTO T-numbers (for DICTO to approve)

Created by DICTO · dictospheres.com · CC BY-SA 4.0 · math-data dataset version 2, 2026-10-24. **A proposal only: no T-number below is used
anywhere yet** (index.csv leaves `universal_number` empty for all of these).

Rule (DICTO 2026-10-23): one universal number per piece, used once and never reused; numbers given by earlier creators come first
(Johnson J, uniform U, Wenninger W, Hart's stellation lists, Mosseri–Sadoc t1–t6, …); a DICTO T-number only where no earlier number exists.
Solids and pieces only (clusters, structures, compounds and curved bodies are not numbered here). Order: the order of first publication
(finding number, then paper number), as in index.csv.

**Where to start.** No published paper uses a T-number (searched: every paper.src.html/paper.html in the research papers folder).
Two earlier uses exist outside the papers: (1) the app's **DICTO Ball set 1** uses the working labels B1, T1, T2 (unpublished; DICTO's
names still to be asked, 2026-10-20); (2) the note "T1 = Cleo" (piece-set naming example, "DICTO Tile set 1 (EKP) piece T1 (Cleo/V*4)"),
but Cleo already has an earlier number, Mosseri–Sadoc t4 (DICTO confirmed 2026-10-23), so by the rule it takes no T-number.
To be safe this list **starts at T3** and keeps T1 and T2 free until DICTO decides. If the Ball set labels are only set-local and Cleo
keeps t4, the list can start at T1 instead (every number moves down by two).
