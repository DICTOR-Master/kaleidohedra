# DICTO D-numbers

Created by DICTO · dictospheres.com · CC BY-SA 4.0 · math-data dataset version 2, 2026-10-24; version 3, 2026-10-27.

**The scheme (DICTO 2026-10-24).** A D-number is DICTO's permanent catalogue number: one per new solid or piece of DICTO's, given in the
order of first publication, used once and never reused (even if a shape is retired or renamed). Numbers given by earlier creators come
first and are kept as they are; D-numbers are only for DICTO's new shapes. They are written in the `universal_number` column of `index.csv`.

| label | what it numbers | example |
|---|---|---|
| **D1, D2, …** | DICTO's permanent catalogue number of a new solid or piece | D1 = DICTO skewed rhombic dodecahedron |
| **T1, T2, …** | a piece's label *within one piece set* (set-local, not a catalogue number) | DICTO Ball set 1: B1, T1, T2 |
| **#n** | DICTO's papers | #48 The Golden Split |
| **Fn** | DICTO's findings (Kaleidohedra findings archive) | F21 Lotus Jewel |
| **t1–t6** (lower case) | the Mosseri–Sadoc tiles (earlier creators' numbers) | AXE = t6 ×1/τ, CLEO = t4 ×1/τ, Tricap = t3 ×1/τ |
| J, U, W, Hart | Johnson solids, uniform index (Maeder), Wenninger models, Hart's stellation lists | Delilah = U5; W2 |

**Both numbers.** A shape that has an outside catalogue number keeps it; if it is also one of DICTO's new shapes it would show both,
outside number first, separated by "; " (for example "J1; D9"). No shape in the inventory has both today: the five outside numbers
(Dogstar, AXE, CLEO, Half octahedron P, Delilah) all belong to known or rediscovered shapes, which get no D-number.

## D72–D75: rows that group several pieces (one number per group: DICTO, 24 October 2026)

DICTO decided one D-number per group (24 October 2026). The group numbers come after D71 so that D1–D71 keep their order of first
publication. The pieces inside a group are told apart by their labels within the group (as T labels within a piece set).

| D | row | what it holds |
|---|---|---|
| D72 | Dented tetrahedron L/R (golden-key octet) (#37) | two hands (L, R) of one shape: one number with L/R, or two numbers |
| D73 | DICTO Fill set 1 / 2 pieces (grown bipyramid, grown tetrahedra L/R) (#37a) | Fill set 1 F1, Fill set 2 F1, F2, F3 (#37a): up to four shapes |
| D74 | Cleo Towers (8 tower pieces) (#43) | eight tower pieces (#43) |
| D75 | Polar Cleo Towers (7 tower pieces + core ray) (#43) | seven tower pieces and the core ray (#43) |

## Open questions for DICTO

1. Grouped rows D72–D75: one number per group — DECIDED by DICTO, 24 October 2026.
2. Delilah (the regular octahedron, U5; W2): its row is named "Delilah" as briefed; under the one-name rule (an established literature
   name keeps that name with DICTO's beside it) it could read "Regular octahedron (Delilah)". DICTO's call. It has no D-number (a known shape).
3. (version 3) The Icosaxes Hexa and the Lotus Hexa are filed as clusters (no D-number, as the DICTO Hexa); if DICTO wants them numbered
   as solids, they would take the next free numbers (D84, D85).
4. (version 3) The Triskelion Tetrahedron is filed as new (D82), as Samson was (a named member of Samson's sliding family, #57); #57's study
   notes that it is congruent to the cubic octet's piece at 5/24, so it is not new to the stackings. DICTO's call.
5. (version 3) Named in the same papers but not yet in the inventory, so without numbers: the keyed forms Sonsam-K, Lahdeli-K, Ian Dury-K
   and Rhombo-K (#56), and the Icosaxes Bloom, Bud and Seed, Lotus Jewel Bloom, Bud and Seed, and the Icosaxes Kagome (#59).
