## Theorems (all for Mathlib's `CoxeterMatrix.A 4`; Mathlib has no separate `A₄`)

Faces `Fin 120`; `A4.r i` = rolling across the ridge of type `i` (`i = 0..3`).

| statement | Lean name | kind |
|---|---|---|
| face `x` is dual to the corner `corner x` of the permutahedron; the 120 corners are distinct permutations of (5,4,3,2,1), face 0 ↔ (5,4,3,2,1); rolling across the ridge of type `i` swaps the entries `5−i`, `4−i` (one edge of the permutahedron) | `A4.corner_zero`, `A4.corner_perm`, `A4.corner_injective`, `A4.roll_corner` | kernel check |
| the rolls form a roll model (involutions, distance changes by 1, corner condition) and satisfy the Coxeter relations of `A 4` | `A4.model`, `A4.lifts` | kernel check |
| the Coxeter group has 120 elements; every element has length ≤ 10; exactly one has length 10 | `A4.card_group`, `A4.length_le`, `A4.existsUnique_length_eq` | general + kernel check |
| Matsumoto's theorem; word reduction | `A4.matsumoto`, `A4.reduce` | general |
| **rolling law** between any two faces: two shortest rolls are joined by corner moves; every roll → a shortest roll by corner moves and cancellations | `A4.rolling_law`, `A4.rolling_reduce` | general |
| **10 mirrors** (Mathlib's `IsReflection`) | `A4.card_mirrors` | general + kernel count |
| **every longest shortest roll (10 rolls), from any face, crosses every mirror exactly once** | `A4.longest_crosses_each_once` | general |
| **transitivity**: for any faces `x, y` there is a permutation `σ` of the 120 faces with `σ x = y` and `σ ∘ r i = r i ∘ σ` for every `i`; such a `σ` is determined by one value | `A4.transitive`, `A4.transitive_unique` | general (new: `RollModel.transitive`, `RollModel.transitive_unique`) |

Exact statements:
```lean
theorem A4.card_mirrors : Nat.card {t : M.Group // cs.IsReflection t} = 10
theorem A4.longest_crosses_each_once {ω : List (Fin 4)} (hω : cs.IsReduced ω) (hl : ω.length = 10)
    (w : M.Group) {t : M.Group} (ht : cs.IsReflection t) : (mirrorsCrossed cs w ω).count t = 1
theorem A4.transitive (x y : Fin 120) :
    ∃ σ : Fin 120 ≃ Fin 120, σ x = y ∧ ∀ i z, σ (r i z) = r i (σ z)
```
`transitive` is the combinatorial half of the 3D theorem `fair`. The other half (each `σ` is an isometry of ℝ⁴
mapping the die onto itself) needs the exact die and is part of the geometric step.

## Method
* `RollingLaw/Basic.lean`, `RollingLaw/Coxeter.lean`: **identical copies** of the 3D study
  (2026-11-24-lean-rolling-law; checked with `diff`), so this project does not load the 3D dice.
* `RollingLaw/General.lean`: `mem_iff_of_card`, `mirrorsCrossed`, `mirrorsCrossed_swaps`, `crosses_each_once`,
  `isReflection_iff`, `card_reflections` copied unchanged from the 3D `Die.lean` / `Mirrors.lean`; new:
  `roll_comm`, `transitive` (left multiplication by `g = w_y w_x⁻¹`, carried to the faces by `faceEquiv`;
  it commutes with rolls because rolling is right multiplication), `transitive_unique` (both maps are
  determined by the image of the base face, since every face is a roll sequence from it).
* `RollingLaw/A4.lean`: the instance; every finite condition by `decide +kernel`.
* `RollingLaw/Data/A4.lean`: tables generated by `gen/a4.py` (`python3 gen/a4.py RollingLaw/Data`): corners =
  permutations of u = (5,4,3,2,1), face 0 = u, roll `i` swaps the values `u[i], u[i+1]` (the face of `w` goes to
  the face of `w s_i`), breadth-first numbering, distances and shortest words; `lt` (the coordinate swaps on faces) and `lw` (swaps from face 0 to each face). Data only; nothing in the
  generator is trusted.
* Credit: Matsumoto's theorem (H. Matsumoto, C. R. Acad. Sci. Paris 258 (1964)); the inversion-sequence
  argument for the mirrors uses Mathlib's `CoxeterSystem.IsReduced.nodup_leftInvSeq`. The counts 120, 10, 10
  agree with the known values for A4 = S5 (|W| = 5!, N = 5·4/2 reflections = length of the longest element;
  J. E. Humphreys, *Reflection Groups and Coxeter Groups*, 1990, §1.6–1.8).

Sources checked: the Cox–Little–Schenck book page (errata only, no chapter text; see M4 section); Mathlib `Analysis/Convex/Hull.lean` (`LinearMap.image_convexHull`, used); Mathlib at this pin (`Mathlib/GroupTheory/Coxeter/Matrix.lean`: `CoxeterMatrix.A n`, `B n`,

## M4 and M7 for A4 (`RollingLaw/A4Geometry.lean`)

Coordinates: ℝ⁵, the die lies in the hyperplane `y₀+⋯+y₄ = 0` (a copy of ℝ⁴). Face `x` has normal
`nR x = corner x − (3,3,3,3,3)` (a permutation of (2,1,0,−1,−2)); the die is
`Die = {y : ∑ y = 0 and nR z ⬝ y ≤ 1 for all 120 faces z}`; face `x` has the four vertices
`PR x k = vZ x k / ht k`, where `vZ x k` is `4−k` at the positions of the `k+1` largest entries of `corner x`
and `−(k+1)` elsewhere (5 × a fundamental weight of A4, moved to face `x`), heights `ht = (10,15,15,10)`.
All data integer; real statements by casting.

| statement | Lean name |
|---|---|
| the die is convex | `A4.convex_die` |
| **support**: for every face `z` and every vertex `PR x k`, `nR z ⬝ PR x k ≤ 1`, with equality iff `PR x k = PR z k` (the vertex of type `k` of `z`) | `A4.support` |
| **facets**: `{y ∈ Die : nR x ⬝ y = 1} = convexHull {PR x 0, …, PR x 3}` for every face `x` | `A4.facet` |
| **fair**: for any faces `x, y` there are a coordinate permutation `τ` (an isometry) and a roll-preserving face permutation `σ` with `σ x = y`, `v ∘ τ ∈ Die ↔ v ∈ Die`, `nR (σ z) = nR z ∘ τ`, `PR (σ z) k = PR z k ∘ τ` | `A4.fair` |
| **every roll-preserving permutation of the faces is realised by such an isometry** | `A4.roll_symmetry_isometry` |

Method (no check of every face against every vertex):
* the reflection in the mirror `y_j = y_(j+1)` (swap of coordinates `j, j+1`; `j = 0..3`, the simple
  reflections acting on the left) permutes the faces (table `lt`, kernel check `l_cv`) and commutes with every
  roll (`l_r`); every face is reached from face 0 by such reflections (`lw`, `lw_spec`). A product of these
  carries normals and vertices of each face to those of its image (`Sym`, `sym_Le`), and is an isometry since
  it permutes coordinates (`dotR_comp`). The products are all permutations of the 5 coordinates (the
  10 transpositions are the 10 mirrors).
* so `support` for all 120 × 120 × 4 (face, vertex) pairs follows from **480 checks**: every face against the
  four vertices of face 0 (`base_q`); for H4 this is 14 400 × 4, not 14 400 × 2 640;
* `facet` at face 0 uses **only the four neighbours** of face 0: for `y` in the die on the plane of face 0,
  the plane of neighbour `r k 0` gives `y_k ≥ y_(k+1)`, which is the `k`-th barycentric coordinate
  `(y_k − y_(k+1))·ht k / 5 ≥ 0`, and the coordinates sum to `nR 0 ⬝ y = 1` (`facet0`); then it is moved to
  every face by the reflections;
* `fair` composes the two reflection products for `x` and `y`; `roll_symmetry_isometry` uses
  `transitive_unique` (a roll-preserving permutation is fixed by one value).

**Wall criterion: what was checked.** The statement in D. Cox, J. Little, H. Schenck, *Toric Varieties*
(AMS 2011), §6.1, could **not be opened**: the authors' book page offers only the errata PDF, no chapter text;
copies found by search are not author or publisher releases and were not used. So it is **not cited**. It is
also **not needed** here: for the reflection dice the global inequality comes from the symmetry reduction above
(proved in Lean), and the facet identity from the neighbour planes (proved in Lean). Nothing in this
milestone rests on an unchecked statement.

**What remains (precisely).**
1. The general local-to-global lemma (complete simplicial fan + convexity across every wall ⇒ convex) is
   **not formalised**. The global half of `support` uses the 480 base checks, which are face-against-vertex
   checks at one face (4·|F| in total), not face–neighbour checks. A proof from neighbour checks alone needs
   either the general lemma (degree argument + wall criterion) or the root-system fact that the normal
   decreases along each shortest roll away from face 0 against a dominant weight; neither is done. For all
   reflection dice the symmetry route already has the same order of cost (4·|F| checks).
2. Not proved: the four vertices of each face are affinely independent (each facet is a genuine
   tetrahedron, so none of the 120 inequalities is redundant). One 4 × 5 integer rank check at face 0, moved
   by the reflections.
3. D4, B4, F4 by the same file with new data; H4 needs ℤ[√5] arithmetic (as `Q5` in the 3D study) and a
   non-permutation symmetry (the H4 mirrors as exact matrices, as `Fair.lean` in 3D).
