This folder contains the input and output of the ODA-3D benchmark applied to CT stacks of one eye from each of the following species, used in https://doi.org/10.1101/2020.12.11.422154:
	*Drosophila melanogaster*
	*Apis mellifera*
	*Dielephila elpenor*
	*Manduca sexta*

Each stack has it's own folder with the same name. Within each you can find the following:
	./{species}/*.tif -- these are individual images extracted from the original CT scan representing slices of the eye volume.
	./{species}/_prefiltered_stack/*.tif -- the prefiltered layers of the stack, generated by applying the pre_filter method of the CT_Stack class in the ODA module.

./benchmark.py -- this runs the ODA-3D, profiles its performance, and stores the ommatidial_data and interommatidial_data spreadsheets

Running benchmark.py produces the following for each folder:
	./{species}/_compound_eye_data.h5 -- the HDF file storing benchmark data from the ODA-3D pipeline
	./{species}/ommatidia_data.csv -- a spreadsheet with data for each ommatidium, row-by-row
	./{species}/interommatidia_data.csv -- a spreadsheet with data for each inter-ommatidial pair, row-by-row
	./{species}_stats.csv -- descriptive stats for each species

./plot.py -- this plots the data generated by benchmark.py and stores measurements of each stack in a spreadsheet. A number of figures, particularly interommatidial measurements, require manually saving the output when the GUI pops up.

Running plot.py produces the following:
	./lens_diameters/{species}{.svg/.png} -- for each species, we plot eye maps of ommatidial diameters with a colorbar histogram
	./comparison_stats.csv -- spreadsheet comparing the optical measurements of each species
	./benchmark_comparisons.svg -- bar graphs comparing the ODA-3D benchmark results to estimates of the duration of manual segmentation
