## 1. Words

- **Classes:** **DONE** means the repository already has the item (paper, study or commit cited). **PARTLY DONE** means part is there and the rest is new. **NEW** means the repository does not have it; the note says whether it was checked here. **WRONG** means a statement is false or unfounded, and the note says why. **CONTRADICTED** means the repository already holds evidence against it.
- **β:** the chat's β = arctan(1/√2) ≈ 35.264°. #100 uses β₁₀₀ = arccos(1/√3) ≈ 54.74° = π/2 − β, so β₁₀₀ ≡ −β modulo ℚπ. Every value below is written with the chat's β. A sign flip against #100 is this convention and nothing more.
- **D:** every solid tested has its faces on the 2-, 3- and 4-fold axes of the cube. Each interior dihedral is then exactly pπ + qβ, with p rational and q an integer, verified exactly. So Dehn = D ⊗ β with D = Σ q_e L_e. Since β/π is irrational (cos 2β = 1/3), Dehn = 0 exactly when D = 0.

## 4. Where the chat session was wrong

1. **Lead 4, the cell-first sweep.** The chat gives the slice gaps on t ∈ [1, 2] as (1, 1, t − 1). By #105 Lemma 2a the slice at p_i = t replaces the values 1, 2 by 3 − t, which leaves {3 − t, 3, 4, 5}. Written in the chat's (reversed) order, the gaps are **(1, 1, t)**. The chat's formula gives the degenerate (1, 1, 0) at t = 1, where the slice is Kelvin's (1, 1, 1). It also jumps at t = 2, where the next interval starts at (1, 1, 2). The other three intervals and the closed walk are right.
2. **File 03 A2.1.** The chat calls 9, 3 and 15 − 6√5, which are #43's containment constants (R/r)², "the core-turn constants". In the repository the turn constant is c = (hR)² (Turn Theorem). It is 3 for the cube, but 1 on the tetrahedron line and 2.875087² ≈ 8.27 on the icosahedral line (near-but-never-on). The Turn Law writes the dodecahedron–icosahedron turn as λ ↦ 1/λ. The order of a composite with a partner μ ↦ c′ − μ depends on c′ measured in the turn's own normalisation. No such partner exists on those sweeps. The conclusion "the cube–octahedron pair is the only one whose two turns form a finite group" therefore has no basis yet.
3. **Lead 1, the second source.** Bayer–Billera 1985 is about linear relations among flag f-vectors of Eulerian posets and polytopes. It does not contain the colour-typed balance. The relevant classical sources are Stanley 1979 (balanced and a-balanced Cohen–Macaulay complexes; flag h-vector symmetry for spheres) and Björner–Frankl–Stanley 1987. The chat's main point holds. It is also redundant: this repository had named Stanley 1979 on 13 Nov (pure-swap-6d).
4. **Lead 10, the cited evidence.** The chat says DICTO's data show it through "the Concordance records (4 November)". The decisive statement is #100 Theorem 1.1 (7 Nov), an exact formula, and it is already a proof. Read with Debrunner, it already settles #105's open point. So Lead 10 is not new, only not yet written into #105. The chat's value −12√2 β is right in its frame and agrees with #100's +8√2 ⊗ β₁₀₀ after scaling and the β convention.

Redundant rather than wrong: L1a, L2's rows, A1, B1, P1b, P2a–d, P3b, P3c (DONE above). L3's "derived" counts are classical Narayana numbers. L7's Dehn zero holds along the whole line, so "silent zonohedron" rests on Q4 alone.
