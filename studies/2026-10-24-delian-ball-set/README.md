# Delian Ball set (DICTO 10-24)

Question: in DICTO Ball set 1 (roundtet_octet.py), is there a size where the dimpled ball and the rounded tetrahedron have equal volume (2/3 each per cell of volume 2, = Samson = Delilah in #51 frame)?

Result (float, manifold3d on dicto-big-brother): uniform growth reaches 2/3 at k = 1.501 but neighbouring tetrahedra overlap (6.5e-3); growing only the bumps reaches 2/3 for bump radius x1–2.5 but overlaps stay 3e-4 – 2e-3. Equal volume needs each tetrahedron to take half of every neighbouring octahedron; round bumps collide there. Trimming the bumps flat would turn the set into the Delian bond (#51) with rounded corners. Recommendation: stop (one-sentence remark at most).
