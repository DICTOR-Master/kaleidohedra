# OEIS link card (24 Nov 2026)

Square card for the OEIS link on dictospheres.com and Linktree, replacing DICTO's temporary image.
- scripts/diamond.py: diamond network from exact coordinates (two fcc lattices offset by (1/4,1/4,1/4); bonds = nearest neighbours; loose ends removed); gold = a six-atom ring, the shortest closed non-backtracking walk (A400949). House renderer render3d.py, frames by shots.mjs.
- scripts/card.py: card in Orbitron (SIL Open Font License, fonts/OFL.txt).
- renders/oeis-card.jpg: the card (1200 px).
