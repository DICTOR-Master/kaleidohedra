# Kaleidohedra ユーザーガイド

DICTO による Kaleidohedra は、[Rhombiverse](https://rhombiverse.vercel.app) と [Polyhedraverse](https://polyhedraverse.vercel.app) に続く 3 番目の姉妹サイトです。Rhombiverse は**風景**：どの方向にも広がる格子そのもの。Polyhedraverse は**肖像画のギャラリー**：その格子に住む形を、ひとつずつ間近で。Kaleidohedra は**風景を動かします**：格子全体をずらしたり滑らせたりでき、どのピースも一緒に動きます。それが意味を持つ世界に絞っています：3D+ の格子、独自の世界（Euclid–Kepler–Pacioli Cell Network、Targets、シェル、黄金菱面体）、そして平らな展開図から 3D へ入る展開図です。1D と 4D〜6D の世界は Rhombiverse にあります。

ここでは、どのピースも本物の結晶格子の上で空間をすき間なく埋めます。そのため、ピースは格子に空きがある場所にしか置けません。タップでピースを追加し、長押しで取り除き、作ったものをさまざまな表示で眺めてみましょう。

このガイドの前半ではよく使う操作を順に説明し、後半ではすべての操作を一覧にしています。

画面上のボタン名は、アプリに表示されるとおりに書いています（アプリがまだ翻訳していないものは英語のままです）。

## 格子をずらす（シアー）

Kaleidohedra 独自のコントロールは、右上の **⟋ Shear** パネルにあります。格子全体を一度に動かします。作ったものはすべて一緒に滑り、組み立てはいつも通り続けられます。

- **↺ Reset to FCC** は、迷ったときにすべてをふつうの FCC 格子と正則な菱形十二面体に戻します。
- **Towards** は格子の行き先を選びます：**DICTO FCC**（ふつうの FCC 格子から DICTO のずれた格子へ）か **Bain (BCC → FCC)**。
- **Path** はその正確な道筋に沿って滑らせます。停止点ボタン（FCC、halfway、DICTO FCC など）で名前の付いた点へ飛べます。
- **Cell** は同じ格子のままセルの形を変えます：0 はずれただけのセル、1 はすべての辺が等しいセル（DICTO FCC の停止点では DICTO の歪んだ菱形十二面体）。
- **Regularity** メーターはセルを角度で採点します（1 はすべての角が特別な角：36・45・60・70.5・72・90°）。Bain の道筋では、二等辺四面体のうち正四面体になっている数も数えます。
- **◀ Find** と **Find ▶** は、道筋に沿って次に最も規則的なセル、または正六角形が現れる瞬間へ飛びます。先に停止点をタップしてください。
- **Six sliders** で格子の長さ a・b・c と角度 α・β・γ を直接設定できます。
- **Export member** は今の状態を、名前を付けて小さな JSON ファイル（集団のメンバー）として保存します。

Euclid–Kepler–Pacioli Cell Network では、Shear パネルは格子だけを動かします。セルの中心がずれ、各ピースは正多面体のままです。Targets では角度が変わってしまうため隠れます。Kaleidohedra の発見と、その検証方法は [DISCOVERIES.md](https://github.com/DICTOR-Master/kaleidohedra/blob/master/DISCOVERIES.md) にあります。

## はじめに

### 次元を選ぶ

**ENTER** のあと、次元ピッカーが開きます。ゆっくり回る立体で、その面は **2D+** と **3D+** です。格子の上で作るなら **3D+**、平らな展開図を立体に折るなら **2D+**（展開図）をタップします。ドラッグで立体を回せます。ようこそ画面の **3D+**、**EKP**、**Targets** ボタンからは直接入れます。

あとからは **Menu → Change Dimension**、または左上の **Wizard** から切り替えられます。**3D+** にはすべての格子とそのピースが回転するワイヤーフレームで並び、Kaleidohedra 独自の世界もあります。**2D+** は展開図を開きます。

### 最初のピースを置く

空のワールドには、最初のピースが置かれる場所に**オレンジの輪郭**が表示されます。それをタップしてください。あとは、どれかのピースの面をタップすると、その反対側に隣のピースが追加されます。

ピースは 1 つずつ置いていきます。3D+ では最初に **RD**（菱形十二面体）が選ばれています。いま置くピースは左下の **Shape** ボタンに表示されています。タップすると別のピースを選べます。

### ピースを取り除く

- **スマートフォン・タブレット：** ピースを長押しします。
- **マウス：** ピースを右クリックします。右クリックはどのモードでも取り除きます。

直前の変更を取り消すには、右下の **Undo**（↶）をタップします。長押しすると何ステップもまとめてさかのぼれます。取り消しの履歴は次元ごとに別なので、展開図で取り消しても 3D+ の作品には影響しません。

### カメラを動かす

- **回転：** 1 本指でドラッグ、またはマウスの左ボタンでドラッグ。
- **ズーム：** ピンチ、またはスクロールホイール。
- **移動：** 2 本指でドラッグ。

## 何を作るか選ぶ

### 格子ごとのピース

**2D 展開図**（Wizard → 2D+）：2D から 3D へ。パネルで立体を選びます：**ボロノイ細胞**、立方体、RD、TO（切頂八面体）。単純・面心・体心の立方格子の、空間を埋める細胞です。選ぶと、その展開図が薄く表示されます。それをたどり、タップで最初の面を辺ごとに 1 次元のセルで作り、その後は 1 タップで次の面を 1 つ。展開図が完成したらタップで立体に折りたたまれます（表示は **2D+/3D+**）。**折りたたみスライダー**で手で折ったり開いたりでき、**3D+ で開く**で完成した立体をそこへ。長押しで面を 1 つ戻します（または開きます）。立体ごとに進み具合を保存します。 **プラトンの立体**が 2 つ目のグループです：正四面体、正八面体、正二十面体、正十二面体、立方体。**3D+ で開く**は、3D+ のワールドにピースとしてある立体（立方体、RD、TO、正八面体）のときに現れます。Undo の横の **⊘** で、いまの展開図を消せます。

**ペイント**（3D+）：下の列の筆、またはカラーホイール中央のペイントスイッチで、置いたピースの色を塗り替えます。オンにして色を選び、ピースをタップ。オフにすると再び作れます。色分けは「選択」に切り替わり、各ピースが自分の色を見せます。（シェル、黄金菱面体、EKP、Targets はピースを独自に色分けするので、ペイントはありません。展開図にもありません。）下の列の枠が接続トグル（Rhombohedra と Pyrochlore）に使われているときは、筆はそのすぐ上にあります。

**3D+：**

| 格子 | ピース |
|---|---|
| FCC | Rhombic Dodecahedron（RD、菱形十二面体）、Hemi RD、Hourglass、RD Quarter、Cube、Pyramid |
| DICTO FCC | DICTO RD：DICTO が Zometool の青いストラットで作った歪んだ菱形十二面体（60°と72°のひし形が6枚ずつ、辺1で体積φ²）を、ずらした FCC に詰めたもの。DICTO Blocks：その4つのブロック（すべてひし形のブロック2つと平たい菱面体2つ）を面どうしで置けます |
| RD Dual | Cuboctahedron（CO、立方八面体）、Octahedron（八面体） |
| BCC | Truncated Octahedron（TO、切頂八面体） |
| BCC Interstitial | Flattened Octahedron、Disphenoid |
| Elongated Dodecahedron | Elongated Dodecahedron（ED、長菱形十二面体） |
| Hexagonal | Hex Prism（六角柱） |
| Rhombohedral | Rhombohedra（菱面体） |
| Pyrochlore（3D かごめ） | Truncated Tetrahedron（切頂四面体。あいだの四面体は自動で追加されます） |

FCC で試してみましょう。Pyramid を 6 つ置いて Cube を作ります。次に Cube の各面に Pyramid を 1 つずつ足すと、RD になります。その 6 つをまた取り除くと Cube に戻ります。

**RD Quarter** は、RD を分割してできる 4 つの菱面体の 1 つです。RD の角の近くをタップするとその角が埋まり、次に Quarter の面をタップすると、その面の向こう側に鏡像が置かれます。鏡像はかならず RD 格子の上に来るので、Quarter をセルからセルへと伸ばしていけます。Mirror（鏡像）に加えて Copy（複製）も使える自由な菱面体格子には、**Rhombohedra** を使ってください。

### 色

ピースの色は設定の **色分け** で決まります。**シアン**（すべてシアン、既定）、**種類**（ピースの種類ごとの色。表示される一覧で変更可）、**選択**（置いたときの色を保つ）。左下の**色ボタン**で 15 色から選べます。シアンのときは選択に切り替わり、種類のときは置いているピースの種類の色が変わります。切り替えても、置いたときの色は失われません。

| Lattice View | 作品と、選んだピースを 1 段外側に置ける空き場所すべて | Lattice View ボタン（またはコーナーホイールの ⬡）をタップしてピースを切り替え |

## シェル

**ハル**を作る 3D ワールドです。菱形十二面体（RD）のシェルを重ね、シェルごとに色の帯が付き、最初のピースから外側へ数えます。Wizard の 3D+ 画面から選びます。

- **＋ シェル**で次のシェルを埋め、**− シェル**で一番外側を取り除きます。**ハル**でシェルの数え方を選びます：**ステップ**（立方八面体：13、55、147 … 個）、**距離**（球に近づく）、または目標の形（正四面体、立方体、正八面体、RD、切頂八面体）。**トリム**でハルをその形にぴったり平らに切りそろえます。
- **分割**モード：ピースをタップし、**分割**（半分、3 分の 1、4 分の 1、6 分の 1、8 分の 1、12 分の 1、16 分の 1、24 分の 1、48 分の 1）を選びます。**回転**で切り方を変えます。構築モードでは**ピース**メニューで一片だけ置くこともできます。
- **スケール**で大きな RD（×2〜×4）を使って作れます。選んだピースで**×2／×3 に統合**すると大きな RD の輪郭が表示され、**統合を確定**で大きな RD 1 つに置き換わります。分割メニューで元に開けます。
- **情報**にはリング図があります。リングをタップするとそのシェルを隠したり表示したりして中を見られ、どのシェルも取り除けて、帯の色も選べます。

## 黄金菱面体

3D ペンローズ・タイリングの 2 ピースで作る 3D ワールドです。Wizard の 3D+ 画面から選びます。オレンジの輪郭をタップし、面をタップすると、ピースのメニューで選んだ**細長い**か**平たい**ピースが加わります。**ペンローズ判定**は、真の非周期タイリングに属するピースを緑、外れたピースを赤で示します。Lattice View は周りの真のタイリングを表示し、幽霊をタップすると置けます。

同じ 2 つのブロックは、彫刻や造形のための取り出せる骨組み、DICTO の **RHOMBITURE** のピースでもあります：[doi:10.5281/zenodo.23173896](https://doi.org/10.5281/zenodo.23173896)。

## Euclid–Kepler–Pacioli Cell Network (EKP)

ひとつの正確なセルの3D世界です。立方体にユークリッドの屋根を載せると正十二面体になり、屋根を立方体の面で内側へ折り返すと正二十面体になります。立方体・十二面体・二十面体の辺の比は φ² : φ : 1 です。ウィザードの3D+画面で選びます。オレンジの輪郭をタップし、**ピース**（立方体、十二面体、二十面体、大星型十二面体、八面体、星型八面体、黄金長方形）を選んで立体をタップすると、そのセルにまだなければそこへ、あればタップした面の向こうのセルへ置かれます。小さい立体は大きい立体の内側に入るので、**X線**や半透明表示で見てください。**表示**は同じ組み立てを描き直します：**模様**に沿って2つの立体を交互に、市松模様、またはすべての十二面体を結合した外側の面。**頂点**は立方体の角またはすべての頂点を示し、**情報**は空間群を表示します（セル自体は Pm-3、模様ごとに異なります）。十二面体を面の向こうへ伸ばすと、斜めの模様で同じ色のセルにしか届きません。ほかのセルへは立方体の面から伸ばします。**奇数のキューブを回す**は、奇数のキューブ内のすべてのピースを鉛直軸まわりに90度回転させ、隣り合うキューブが交互になるようにします。統合された外側の表面にも適用されます。

そのうち 3 つのピースはケプラーへのオマージュです：立方体の面の中心に頂点を持つ**八面体**（二十面体の頂点はその辺を黄金比で分けます）、立方体の頂点を一つおきに結ぶ 2 つの正四面体がその八面体で重なる**星型八面体**、そして隣のセルの屋根の棟がちょうど出会う、パチョーリの互いに組み合う 3 枚の**黄金長方形**。こうして 5 つの正多面体がすべて 1 つのセルに入れ子になります：二十面体、八面体、四面体、立方体、十二面体。

この世界のもとになっているセルは **Euclid–Kepler–Pacioli セル**、角だけで接する大星型十二面体と二十面体の並びは **Euclid–Kepler–Pacioli ネットワーク**で、どちらも DICTO によるものです。引用：[doi:10.5281/zenodo.23173809](https://doi.org/10.5281/zenodo.23173809)。

## スタディ

Euclid–Kepler–Pacioli のセルに基づく正確な構成を、ひとつずつ見る 3D+ の世界です（Wizard → 3D+ → Studies）。**スタディ**を選びます：**窓**（十二面体から、面で隣り合う 6 つのセルの星形八面体をくり抜くと、十二面体の面の角度のままペンローズの厚い菱形が 12 枚残ります）、**窓と6つの星形八面体**、**正十二面体とドッグスター**（偶数のセルの正十二面体が奇数のセルごとに残す穴は、大きさ 1/φ³ の十二面体の部分的な星形化である 8 本とげの星（ドッグスター）で、そのセルの星形八面体の内側にあります。合わせて空間を埋め、**離す**で離せます）、**窓と星形八面体、市松模様**（星形八面体は窓のもう半分：偶数セルに窓、奇数セルに星形八面体を置くと空間をぴったり埋めます。12 + 4 = 立方体2つ分。**離す**スライダーで離してかみ合う様子を見られます）、**凸にした窓**（各菱形を真っすぐ外へ押し出します。**押し出し**スライダーは黄金点で止まり、黄金菱形が 6 枚現れて全 74 面になります）、**窓から二十・十二面体へ**と**窓から菱形十二面体へ**（**変形**スライダーで菱形がそれぞれへ動きます。凸包は不透明に描かれ、菱形はその上にはめ込まれ、途中は輪郭が透けて見えます）、**引き伸ばした十二面体**（五角形8・六角形4・長方形2。**伸ばし**スライダーは辺1本分で長方形が正方形になる点と、格子の間隔で止まります）。スタディもシアーできます：格子上の正確なコピーとして、またはワンタップで立体そのものとして。

## Stella–Jewel Lattice

2 つの立体が市松模様で空間を埋める 3D+ の世界です（Wizard → 3D+ → Stella–Jewel Lattice）：偶数のセルに**ドラゴンジュエル**（DJ、Studies の窓の立体に DICTO が付けた名前）、奇数のセルに**星形八面体**。水色のドラゴンジュエルをタップして置き、面をタップするとその向こうに立体が増えます。長押しで取り除きます。**表示**で両方の立体と**ドラゴンジュエルだけ**を切り替えます。ドラゴンジュエルどうしは 12 枚のひし形すべてで面を合わせ、星形八面体の形の穴が残ります。**シアー**は Studies と同じく、動くセル中心上の正確なコピーか、充填全体を曲げるかを選べます。**5 回軸**は各ドラゴンジュエルの 6 本の 5 回軸と、各面で窓が置けた 5 つの位置を描き、立方体が選んだものを明るく示します。Lattice View で次に埋められるセルが見えます。

## Sunstar Lattice

偶数のセルに最密な格子充填の正十二面体、それらが奇数のセルに残す穴ごとに**ドッグスター**を置く 3D+ の世界です（Wizard → 3D+ → Sunstar Lattice）。ドッグスターは 8 本とげの星で、大きさ 1/φ³ の十二面体の部分的な星形化そのもの、辺の長さはすべて黄金比です。ドッグスターに囲まれた正十二面体が**サンスター**、太陽と幻日です（DICTO の命名）。水色の十二面体をタップして置き、面をタップするとその向こうに立体が増えます。長押しで取り除きます。**表示**は両方、**ドッグスターだけ**（立方体の角ごとに 4 つが頂点を共有する、3D のカゴメのような格子。タップすると点を共有するいちばん近いドッグスターが増えます）、**正十二面体だけ**。**シアー**と**5 回軸**は Stella–Jewel Lattice と同じです。

## Targets

160個の目標セルの3Dギャラリーです。すべての辺が等しく、辺が特別な角度（36°、45°、60°、70.53°、72°、90°）でのみ交わる空間充填セルを、2通りの厳密な探索で見つけたものです（[TARGETS.md](https://github.com/DICTOR-Master/kaleidohedra/blob/master/TARGETS.md)）。ウィザードの 3D+ 画面で選びます。**種類**（平行六面体、六角柱、菱形十二面体、長菱形十二面体、切頂八面体）とセルを選ぶか、◀ ▶ で順に見ます。名前は種類、TARGETS.md での番号、角度からなり、✓ はすでに Polyhedraverse にあるものです。**表示**でセル単独、面で隣接するセルと一緒、または格子の 3×3×3 ブロックを描き、空間を埋める様子が見られます。面は種類ごとに色分けされます（正方形は青、菱形はピンク、正六角形は金、その他の六角形は紫）。**Info** には面、辺の方向どうしの角度、体積（辺の長さ 1）、充填する格子、Polyhedraverse にあるかどうかが表示されます。ここでは何も組み立てず、角度が正確なままになるようシアーパネルは隠れます。

## 作品を保存する

ワールドは変更のたびに、すべての次元ぶん、このブラウザに自動で保存されます。同じ端末・同じブラウザでサイトを開き直すと元に戻ります。

**設定** では：

- **ワールドをエクスポート** は、すべての 3D+ の格子と世界、展開図を 1 つのファイルに保存します。バックアップや別の端末への移動に使えます。
- **ワールドをインポート** は、エクスポートしたファイルを開きます。**Undo** でインポートを取り消せます。
- コーナーホイールの **Clear World**（⊘）で、空のワールドからやり直します。Undo で元に戻せます。

## 数学を学ぶ

- **Almanac：** すべてのピースと格子の背後にある数学と幾何学。メニュー → Almanac から開きます。
- **What's New** には最近の変更が並んでいます。

# 操作一覧

## 画面のボタン

| 操作 | 内容 |
|---|---|
| Wizard（左上） | 次元と格子を、それぞれのピースとともに見て回る。横の大きなオレンジの文字は、いまいる次元 |
| Shape（左下） | いま置くピース。タップで変更 |
| 色（左下） | 作るときの色。タップで変更 |
| Lattice View | Off と、各ピースの表示を順に切り替え |
| 付け方の切り替え | 複数の付け方があるピースのときだけ表示（Rhombohedra：コピー / ミラー、Pyrochlore：小さい / まるごとの四面体）。タップで切り替え |
| Undo（↶、右下） | タップで現在の次元を 1 段階取り消し。押し続けるとさらにさかのぼる |
| Paint（ブラシ） | 置いたピースの色を塗り替え：オンにして色を選び、ピースをタップ。下の列の接続トグルの位置にあり、そのトグルが必要なときはすぐ上に移ります |
| ⊘ クリア（Undo の隣、展開図） | いまの展開図を消してやり直します。Undo で戻せます |
| メニュー | メニューホイールを開く（キーボード：Tab または Space） |

## コーナーホイール

隅の小さなホイールをドラッグして回し、面をタップして使います。

| 記号 | 操作 |
|---|---|
| ⚙ | 設定 |
| ⛶ | X-Ray |
| ◐ | Duality |
| ⬡ | Lattice View |
| ◇ | メニュー |
| ⊘ | Clear World |
| ↻ | Reload（何かが止まって見えるときに使います） |
| ◯ | Spherical（オフ → 球 → すき間） |
| — | World View |

## メニューホイール

メニューは菱形十二面体です。各面が 1 つのセクションで、面をタップすると開き、**Home** で戻ります。**Almanac** はいつも上の面にあります。

| セクション | 内容 |
|---|---|
| Home | Piece、Color、Change Dimension |
| Piece | RD family、Cube、Pyramid、TO、Flattened Octahedron、Disphenoid、CO、Octahedron |
| RD family | RD、Hemi RD、Hourglass、RD Quarter、ED、Hex Prism、Rhombohedra、Pyrochlore |
| Change Dimension | 2D+, 3D+ |

## 設定

| 設定 | 内容 |
|---|---|
| 視点の感度 | カメラの回転速度 |
| Y軸反転 | 縦方向のドラッグを逆にする |
| 視野角 | カメラのレンズの広さ |
| グラフィック品質 | 低・中・高 |
| FPSメーターを表示 | フレームレートの表示 |
| 音量 | 音の大きさ |
| 言語 | English、日本語、Español、Français、한국어、中文、Русский（ようこそ画面とこのガイドの上部にある 🌐 ピッカーでも変更できます） |
| 色分け | シアン、種類、選択：ピースの色の付け方 |
| 断面表示、軸、位置、反転 | 1 つの軸に沿った切断面 |
| Dualize Preview | 特別な作成モード |
| ワールドをエクスポート、ワールドをインポート | バックアップと復元（すべての次元） |

## キーボードとマウス

| 入力 | 動作 |
|---|---|
| 面を左クリック | ピースを追加 |
| ピースを右クリック | 取り除く |
| 左ドラッグ | カメラを回転 |
| スクロールホイール | ズーム |
| Tab または Space | メニューホイールを開く |
| Escape | メニュー、Wizard、Almanac を閉じる |
| Enter | ようこそ画面から入る |

| ジェスチャー | 動作 |
|---|---|
| 面をタップ | ピースを追加 |
| ピースを長押し | 取り除く |
| 1 本指でドラッグ | カメラを回転 |
| ピンチ | ズーム |
| 2 本指でドラッグ | 移動 |
